# Vortex Academy – Weekly Reports (website)

Static website (no build step). Data, logins and access rules live in the Supabase project "vortex SC" (tables acad_*).

## Deploy on Vercel
1. Push this folder to a new GitHub repository (e.g. vortex-academy-reports).
2. In Vercel: Add New → Project → import the repository.
3. Framework preset: **Other**. Leave build command and output directory empty. Click Deploy.

## First sign-in
Open the site → "First-time setup for the academy admin" → enter the one-time setup code, your name, email and a password.
Then: Admin settings → Logo & mascots (upload logo + 5 mascots) and People & logins (create coach logins).
